# o_poder_do_notebooklm_pythoncomplicacao
Conteúdo criado com base em livros, vídeos e conceitos-chave sobre Python e Lógica de Programação. Utilizando o NotebookLM como ferramenta de aprendizagem ativa.

## 🎯 Objetivos

* **Construir um Segundo Cérebro:** Centralizar conteúdos, referências e insights sobre lógica de programação e a linguagem Python.
* **Desmistificar o Aprendizado:** Demonstrar que o domínio da tecnologia é um processo contínuo, acessível e estruturado.
* **Praticar Aprendizagem Ativa:** Utilizar curadoria de fontes de alta qualidade e engenharia de prompts para resumir, sintetizar e criar guias práticos de estudo.

## 🗺️ Miniguia e Roadmap (100 Dias de Python)

Abaixo está o plano estruturado de estudo gerado a partir do cruzamento de diretrizes do CS50, MITx e do método *100 Days of Code*:

| Período (Dias) | Fase de Aprendizado | Tópicos Principais | Objetivos e Prática Recomendada |
| :--- | :--- | :--- | :--- |
| **01 – 10** | **Alfabetização e Configuração** | Instalação (Python 3), IDLE/Editores, Variáveis e Tipos Primitivos (`int`, `float`, `str`, `bool`). | Configurar o ambiente, entender o *Zen do Python* e realizar operações aritméticas básicas. |
| **11 – 25** | **Lógica e Controle de Fluxo** | Operadores lógicos/relacionais, Estruturas de Decisão (`if`, `elif`, `else`) e Repetição (`while`, `for`). | Criar algoritmos para resolver problemas simples do dia a dia e jogos de adivinhação. |
| **26 – 40** | **Estruturas de Dados Coletivas** | Listas, Tuplas, Dicionários e Conjuntos (`Sets`). | Manipular coleções, usar fatiamento (*slicing*) e aplicar métodos (`append`, `sort`, `update`). |
| **41 – 55** | **Modularização e Funções** | Definição de funções (`def`), argumentos (`*args`, `**kwargs`), escopo de variáveis e módulos. | Dividir o código em blocos reutilizáveis organizados em arquivos `.py` usando `import`. |
| **56 – 65** | **Persistência e Exceções** | Tratamento de erros (`try`, `except`), manipulação de arquivos (`txt`, `csv`, `json`) e bloco `with`. | Garantir tratamento de exceções para evitar travamentos e persistir dados em disco. |
| **66 – 80** | **Orientação a Objetos (POO)** | Classes, Objetos, Atributos, Métodos, Herança e Polimorfismo. | Modelar entidades do mundo real encapsulando dados e comportamentos. |
| **81 – 90** | **Recursos "Pythonicos" Avançados** | List Comprehensions, Decoradores, Geradores (`yield`), Iteradores e Gerenciadores de Contexto. | Escrever código mais legível, conciso e performático com recursos nativos da linguagem. |
| **91 – 100** | **Especialização e Projetos** | Bibliotecas para Análise de Dados (`Pandas`, `NumPy`) ou Web (`Flask`, `Django`). | Desenvolver um projeto de portfólio completo (ex: análise de dados ou aplicação web). |
